# 从“梦境记录”到“个人梦境电影工作室”

## 第一优先级：把成片质量做稳

### 1. 自动导演，而不是自动拼接

- 根据叙事转折控制镜头数，避免每个句子都生成一个镜头。
- 开场建立空间，中段跟随动作，结尾留情绪余韵。
- 旁白按真实配音时长调整镜头，不机械固定 5 秒。
- 自动输出“导演说明”，所有决定仍可手动覆盖。

### 2. 视觉一致性系统

- 人物参考图、服装、年龄、画风和色板作为跨镜头锚点。
- 每镜头生成 2–4 个候选，人工选首帧，再生成动态。
- 支持尾帧衔接下一镜头首帧，减少空间跳变。
- 对人物脸部、建筑、字幕乱码做质量检查与重试。

### 3. 可恢复的云任务与资产管理

- 本地预览继续使用文件任务；正式部署改为数据库 + worker + 对象存储。
- 每镜头记录供应商、模型、成本、耗时、提示词版本和素材哈希。
- 修改一个镜头只重渲染它与最终合成，不重复消耗其它镜头。
- 支持取消、超时、供应商切换、指数退避和失败原因分类。

## 第二优先级：声音决定“电影感”

### 4. 多音色配音台

- 火山/Azure/OpenAI 兼容 TTS 任选，按中文自然度、延迟、价格实测后再定默认。
- 每梦保存旁白者、语速、音高、情绪与停顿；支持逐句试听。
- 自动依据配音真实时长调整镜头，并提供“保留画面节奏”选项。
- 用户授权后可使用自己的录音或声音档案；必须明确告知合成与存储方式。

### 5. 自适应音景

- 雨、风、房间低鸣、远处人声等分层环境声，而非一首音乐铺到底。
- 旁白出现时自动 ducking，转场处做音量与混响衔接。
- 根据梦境情绪给出克制的音乐候选，标记授权与来源。
- 最终响度统一，避免镜头间忽大忽小。

## 第三优先级：模型供应商策略

### 6. 即梦 / 火山视频模型

- 适合评估中文提示词、东方生活场景、人物动作与国内访问稳定性。
- 接入前用小样本验证：首帧一致性、运动幅度、真实可选时长、横竖屏、审核失败、下载有效期与成本。
- 在现有 provider adapter 上实现提交/轮询，不复制任务与合成代码。
- 与 Grok 做同一组分镜盲测，不预设哪家一定更好。

### 7. 可替换的视频供应商

- 为每个镜头指定供应商：关键镜头用高质量模型，过渡镜头用便宜模型。
- 支持本地/私有部署模型作为隐私与成本选项。
- 统一任务协议、能力探测和错误模型，UI 只展示账号真实可用的参数。

## 更有野心的产品方向

### 8. 交互式梦境回放

- 原录音、旁白、文字和画面按时间轴联动。
- 点击人物或场景跳到相关梦；从“这部电影”回到“那晚的记忆”。
- 输出可分享的只读放映页，默认私密并允许撤回。

### 9. 长期梦境母题与年度电影

- 识别反复出现的人、地点、颜色和情绪，不只统计关键词。
- 将一个月/一年的梦剪成主题短片，并保留每条素材的原始出处。
- 让用户看到“哪些意象变了”，而不是给出玄学式人格判断。

### 10. 私密协作与创作工具

- 导出可编辑工程：分镜 JSON、字幕 SRT、WAV  stems、FFmpeg 工程清单。
- 支持导入剪辑软件继续精修；不只给一个不可修改的 MP4。
- 提供端到端加密备份、媒体过期策略和彻底删除能力。

## 推荐实施顺序

1. 即梦适配器 + 首帧/尾帧 + 小样本质量评测。
2. 配音逐句试听 + 时长驱动分镜 + 自动闪避。
3. 云端持久 worker、对象存储和镜头级成本统计。
4. 视觉一致性、多候选关键帧与自动质量检查。
5. 交互式回放、主题电影和开放工程导出。
